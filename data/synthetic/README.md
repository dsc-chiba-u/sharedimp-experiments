# Synthetic data

Generated by `python/sharedimp_exp/make_synthetic.py` (fixed seeds, values
rounded to 6 decimals so that the CSV text is the data in both languages).
`manifest.json` lists every file with its task, columns, sha256, generator
parameters and, for the positive control, the closed-form reference values.
Do not edit the files; change the generator and regenerate.
`python -m sharedimp_exp.make_synthetic --check` verifies that the committed
files are reproduced byte for byte.

The `fold` column is the only source of train/assessment splits: one split per
label, in increasing label order, in R and in Python.
